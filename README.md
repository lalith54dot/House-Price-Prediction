# House Price Prediction

## Project Overview

This project uses machine learning techniques to predict house prices based on different property features.

## Objective

The main objective of this project is to build a machine learning model that can estimate house prices using available property-related features.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Steps

1. Loaded the dataset using Pandas.
2. Performed data preprocessing.
3. Explored the dataset and analyzed the features.
4. Performed exploratory data analysis.
5. Analyzed correlations between features and house prices.
6. Prepared the data for machine learning.
7. Trained regression models.
8. Evaluated the model performance.
9. Used the trained model to predict house prices.

## Files

* `Predicting_House_Prices.ipynb` – Main house price prediction notebook.
* `Polynomial_Regression.ipynb` – Polynomial regression implementation.
* `house_prices.csv` – Dataset used for the project.

## How to Run

Clone the repository and open the notebooks using Jupyter Notebook or Google Colab.

```bash
git clone https://github.com/YOUR-USERNAME/House-Price-Prediction.git
```

Then open:

```text
Predicting_House_Prices.ipynb
```
